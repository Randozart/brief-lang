# spec/old_docs

Archived documentation from earlier Brief compiler versions. These documents are no longer authoritative — refer to `spec/SPEC.md` and `spec/LANGUAGE-REFERENCE.md` for current specifications.

## Organization

### language_specs/
Version-specific language specifications and architecture documents.
- `v4-*.md` — v4.x era specifications (2026-04-04)
- `SPEC-v*.md` — Stubs indicating consolidation into spec/SPEC.md
- `EMBEDDED_BRIEF_*.md` — Embedded Brief version stubs

### getting_started/
Historical getting started guides and onboarding documentation.
- `GETTING-STARTED.md` — Original Brief tutorial
- `ARCHITECTURE.md` — System architecture overview
- `FFI-STDLIB-REFERENCE.md` — Foreign Function Interface guide

### design/
Design documents for features and issues considered during development.
- `DESIGN-FEATURE-*.md` — Proposed feature designs
- `DESIGN-ISSUE-*.md` — Issue analysis and proposed solutions

### implementation/
Implementation plans, progress tracking, and summaries.
- `IMPLEMENTATION-PLAN*.md` — Roadmap documents
- `IMPLEMENTATION-SUMMARY.md` — Status summaries
- `STDLIB-REDESIGN.md` — Standard library redesign

### ffi_design/
Foreign Function Interface design and specification documents.
- `FFI-DESIGN-SUMMARY.md` — FFI design overview
- `IMPLEMENTATION-PLAN-FFI-v6.2.md` — v6.2 FFI plan
- `SPEC-v10.2_FFI.md` — FFI specification
- Stubs for FFI guides and Metropolitan FFI variants

### hardware_design/
Hardware target (SystemVerilog) design documents.
- `HARDWARE_CONFIG_GUIDE.md` — Hardware configuration guide
- `HARDWARE_VALIDATION_DESIGN.md` — Validation design

### stubs/
Placeholder files for documents whose content was consolidated elsewhere.
These are minimal (2-4 lines) and serve as version tracking markers.
