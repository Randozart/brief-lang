## Changes

This baseline adds the **batch-loop optimization**: when a loop body contains hoistable `when` guards with side-effecting calls (periodic prints, termination), the loop is split into an outer structural loop and an inner pure-compute loop. The inner loop has no branches or function calls, enabling LLVM's if-conversion.
