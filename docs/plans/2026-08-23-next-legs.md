## Leg 1 — Async Scheduler Phase A3 (run-queue model)

Simple deterministic scheduling without coroutines. Spawned tasks enter a
FIFO run-queue; the interpreter drains the queue at await/scheduler points.

- `spawn fn(args)` → creates Ready task, returns handle (already done in A2)
- `await task` → if task is Ready, execute it now and return result
  (already done in A2)
- **NEW:** `yield;` inside a task body marks a checkpoint — remaining
  statements after yield are deferred to a second pass
- **NEW:** multiple spawns create multiple queue entries; awaits process
  them in FIFO order (deterministic interleaving)

### Implementation

In `eval_task_spawn`: store the FunctionDef body + bindings snapshot.
In `Expr::Await`: execute pending tasks from the table in insertion order.
`Statement::Yield` in eval: sets a flag on the current task; the remaining
statements in the body are collected into a continuation closure.
