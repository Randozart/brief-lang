# Generalize A006: Direct SSA Loop for All Programs Without Async/MMIO

**Date:** 2026-06-10
**Author:** Performance Investigation
**Status:** Implementation

## Background

A006 (commit ff326e3) eliminated `@reactor_tick` for single-txn, no-trigger
programs, letting LLVM promote `%State` fields to phi nodes. Benchmarks with
hot-loop FFI reached parity or exceeded C.

## Generalization

The condition `txns.len() == 1 && !has_wake_triggers && enumerable.is_none()`
is too conservative. `emit_ssa_main` already handles multiple txns and the
identifier lookup path already inlines trigger sampling via `emit_trg_load`
on first reference. The only remaining blockers for phi-capable codegen are:

| Feature | Blocks phi promotion | Why |
|---|---|---|
| Async thread pool | Yes | Independent state copies + `fired_mask` alloca |
| MMIO fields | Yes | Volatile semantics prevent SROA |
| Wake triggers | No | Sampled inline via lazy `emit_trg_load` |
| Enumerable triggers | No | Switch dispatch already in `main()` via `emit_folded_multi_main` |

## Changes

### 1. emit_ssa_main: Add `has_wake_triggers` parameter

```rust
// Before:
pub(crate) fn emit_ssa_main(&mut self, out: &mut String, txns: &[...])

// After:
pub(crate) fn emit_ssa_main(&mut self, out: &mut String, txns: &[...], has_wake_triggers: bool)
```

### 2. emit_ssa_main: Add wake path

After txn bodies, before `br` back to `tick`:

```rust
if has_wake_triggers {
    // Exit check true→done, false→wait then loop
    writeln!(out, "  br i1 {}, label %done, label %wait", tr).ok();
    writeln!(out, "  wait:").ok();
    writeln!(out, "  call void @__rt_wait()").ok();
    writeln!(out, "  br label %tick").ok();
} else {
    writeln!(out, "  br i1 {}, label %done, label %tick", tr).ok();
}
```

And for programs without exit condition:
```rust
} else if has_wake_triggers {
    writeln!(out, "  call void @__rt_wait()").ok();
    writeln!(out, "  br label %tick").ok();
} else {
    writeln!(out, "  br label %tick").ok();
}
```

### 3. Relax A006 condition

```rust
// Before:
} else if txns.len() == 1 && !has_wake_triggers && enumerable.is_none()
    && self.async_txn_names.is_empty() && self.mmio_fields.is_empty()

// After:
} else if self.async_txn_names.is_empty() && self.mmio_fields.is_empty()
```

### 4. Update call sites

All `emit_ssa_main` call sites must pass `has_wake_triggers`:
- A005 path (bounded_pre check)
- A006 path (new generalized)

## What remains for @reactor_tick

Only async dispatch and MMIO. Everything else: triggers, wake, enumerable,
multi-txn — goes through `emit_ssa_main`.
