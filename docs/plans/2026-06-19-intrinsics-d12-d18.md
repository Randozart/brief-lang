# Intrinsic Domains D12–D18 + Extras — Full OS Coverage

**Date:** 2026-06-19
**Status:** Implementation started
**Total new intrinsics:** 35 (27 planned + 8 extras)

## Motivation

Brief's intrinsic system already covers D1–D11 (~75 direct libc intrinsics) for
POSIX systems. The remaining 7 planned domains (D12–D18) plus a few extras fill
the gaps needed for "runs on (just about) every OS from the get-go":

- **Entropy/Random** — no program exists without it (D12)
- **System Info** — adaptive behavior, diagnostics (D13)
- **Debugging** — crash diagnostics, assertion failures (D14)
- **Scheduling** — cooperative multitasking (D15)
- **User/Group** — security, sandboxing, permissions (D16)
- **Threading** — concurrency primitives (D17)
- **Resource Limits** — DoS prevention, sandboxing (D18)
- **Extras** — error messages, temp files, dynamic loading, terminal info

## Codegen Categories

| Category | Pattern | When used |
|----------|---------|-----------|
| **Direct** | Inline libc call in LLVM IR | Simple 1:1 wrappers (getuid, abort, sysconf) |
| **Shim** | `brief_rt.c` function with platform `#ifdef` | Multi-step ops, struct handling, cross-platform abstraction |

## Platform Abstraction Strategy

All new intrinsics use **Direct Libc** for the POSIX path. Where the POSIX
function doesn't exist on Windows, the LLVM backend calls a `__name__` C
shim in `brief_rt.c` that uses `#ifdef _WIN32` / `#ifdef __linux__` etc.
to dispatch to the platform-equivalent API.

This keeps the compiler backend OS-agnostic — platform logic lives in C.

## Implementation Pattern (per intrinsic)

For every new intrinsic variant, the following files are modified:

1. **`src/ast.rs`** — Add variant to `Intrinsic` enum (in domain section)
   - Append at the end of the enum, before macro variants
   - Add to `from_name()` (alphabetical position)
   - Add to `name()` (alphabetical position)
   - Add to `has_side_effects()` — all new intrinsics have side effects (return false for pure, true for observable)

2. **`src/typechecker.rs`** — Add return type in the `IntrinsicCall` match
   - `Type::Int` for raw integers
   - `Type::String` for string returns
   - `Type::Void` for abort/thread_exit

3. **`src/interpreter.rs`** — Add eval match arm in `Expr::IntrinsicCall`
   - Use `libc::*` for POSIX calls
   - Return `Value::Int(n)` or `Value::String(s)` or `Value::Void`

4. **`src/backend/llvm/emit_expr.rs`** — Add LLVM codegen match arm
   - **Direct**: Emit `declare` + `call` inline
   - **Shim**: Emit `declare` in `emit_toplevel.rs` + `call` in `emit_expr.rs`

5. **`lib/runtime/brief_rt.c`** — Add Shim C function (if Shim category):
   - Function name: `__name__` convention
   - Platform `#ifdef` guards for cross-platform support

6. **Tests**: Add to appropriate modules
   - `src/ast.rs` — roundtrip test for `from_name` + `name()`
   - `src/interpreter.rs` — eval tests (type errors, basic calls)
   - `src/typechecker.rs` — return type inference tests

## Cross-Platform Notes

### Windows-equivalent APIs (for brief_rt.c shims)

| POSIX | Windows | Used by |
|-------|---------|---------|
| `getrandom()` | `BCryptGenRandom()` | `getrandom#` |
| `gethostname()` | `GetComputerNameA()` | `hostname#` |
| `uname()` | `GetVersionExA()` + `GetSystemInfo()` | `uname#` |
| `getuid()` / `geteuid()` | `GetUserNameA()` + sid | `getuid#` |
| `pthread_create` | `CreateThread()` | `thread_create#` |
| `pthread_mutex_*` | `CRITICAL_SECTION` | `mutex_*#` |
| `pthread_cond_*` | `CONDITION_VARIABLE` | `condvar_*#` |
| `dlopen()` / `dlsym()` | `LoadLibraryA()` / `GetProcAddress()` | `dlopen#` / `dlsym#` |
| `mkstemp()` | `GetTempFileNameA()` | `mkstemp#` |
| `sched_yield()` | `SwitchToThread()` | `sched_yield#` |
