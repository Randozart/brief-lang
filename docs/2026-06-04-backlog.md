# Backlog — 2026-06-04

### Urgent fixes (in order)

1. **Kalman DFE fix** — `collect_ffi_arg_identifiers` in `transition_graph.rs` has `_ => {}` catch-all
   that silently drops `Expr::Identifier` leaf values. FFI args like `__print_float(energy + ei + ej)`
   recurse to the leaves `energy`, `ei`, `ej` but never insert them into the live seed set.
   The fixpoint loop never traces backward to `x0, p00, ...`.
   - Fix: change `_ => {}` to `_ => collect_identifiers(expr, out)`. One line.
   - Also revert the `collect_precondition_identifiers` hack already added (wrong approach).
   - Revert the Kalman benchmark to its original form (with `x0 == x0` preconditions, which
     will be replaced by the DFE fix — the self-identity check was a workaround).

2. **Decreasing counter universal loop** — `extract_bounded_pre` only matches `Lt`/`Le`, not `Gt`/`Ge`.
   And `emit_folded_loop` unconditionally emits `icmp slt`. Programs like `[count > 0][count == 0]`
   either hang or fall back to O(N) tick-per-iteration.
   - Add `ConvergeDirection` to `BoundedPre`, thread through fold params, branch on direction in loop header.
